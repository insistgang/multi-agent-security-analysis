# 技术架构文档

## 1. 系统总体架构

### 1.1 架构设计原则

本系统采用分层解耦的微服务架构，遵循以下设计原则：

- **单一职责原则**：每个智能体专注于特定领域的威胁分析
- **开放封闭原则**：系统对扩展开放，对修改封闭
- **依赖倒置原则**：高层模块不依赖低层模块，都依赖抽象
- **高内聚低耦合**：模块内部高度内聚，模块之间低度耦合

### 1.2 技术栈选型

| 层次 | 技术选型 | 版本 | 选型理由 |
|------|---------|------|---------|
| 大语言模型 | Qwen2-7B-Instruct | 2.5 | 中文支持好，性能优异，开源可商用 |

```python
class RouterAgent:
    def __init__(self):
        self.routes = {
            'web_attack': WebAttackExpert(),

            'illegal_connection': IllegalConnectionExpert()
        }
        self.keyword_mapping = {
            'sql': 'web_attack',

            'malware': 'illegal_connection',

    async def route(self, alert_data):

        route_scores = self.calculate_route_scores(keywords)
        selected_route = max(route_scores, key=route_scores.get)

        return {
            'route': selected_route,
            'confidence': route_scores[selected_route],
            'target_agent': self.routes[selected_route]
        }
```

### 2.3 专家智能体（Expert Agents）

#### 2.3.1 通用架构
```python
class ExpertAgent:
    def __init__(self, model_path, expert_type):
        self.model = self.load_model(model_path)
        self.rag_system = RAGSystem(expert_type)
        self.knowledge_base = KnowledgeBase(expert_type)

    async def analyze(self, alert_data):
        # 1. 上下文增强
        enhanced_context = await self.rag_system.retrieve(alert_data)

        # 2. LLM推理
        prompt = self.build_prompt(alert_data, enhanced_context)
        raw_result = await self.model.generate(prompt)

        # 3. 结果解析
        structured_result = self.parse_result(raw_result)

        # 4. 置信度评估
        confidence = self.calculate_confidence(
            alert_data, structured_result
        )

        return {
            'result': structured_result,
            'confidence': confidence,
            'processing_time': self.processing_time,
            'context_used': enhanced_context
        }
```

### 2.4 融合分析引擎（Fusion Engine）

#### 2.4.1 融合策略
1. **加权投票法**：根据专家智能体的置信度进行加权
2. **证据理论**：使用D-S证据理论处理不确定性
3. **冲突检测**：识别并处理专家意见冲突
4. **元学习**：根据历史表现调整权重

#### 2.4.2 实现算法
```python
class FusionEngine:
    def __init__(self):
        self.agent_weights = {
            'web_attack_expert': 0.4,
            'vulnerability_expert': 0.35,
            'illegal_connection_expert': 0.25
        }
        self.conflict_threshold = 0.3

    async def fuse_results(self, expert_results):
        # 1. 提取各专家的结论
        conclusions = [r['conclusion'] for r in expert_results]
        confidences = [r['confidence'] for r in expert_results]

        # 2. 检测冲突
        conflict_score = self.detect_conflict(conclusions)

        if conflict_score > self.conflict_threshold:
            # 存在冲突，启动冲突解决机制
            return await self.resolve_conflict(expert_results)

        # 3. 加权融合
        weighted_result = self.weighted_fusion(
            conclusions, confidences
        )

        # 4. 生成最终报告
        final_report = self.generate_report(
            weighted_result, expert_results
        )

        return final_report
```

```python
class OptimizedRetriever:
    def __init__(self):
        self.embedder = SentenceTransformer(
            'sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2'
        )
        self.index = ChromaDB(
            persist_directory="./vector_db",
            embedding_function=self.embedder.encode
        )
        self.cache = TTLCache(maxsize=1000, ttl=3600)

    async def retrieve(self, query, top_k=5):
        # 1. 检查缓存
        cache_key = hashlib.md5(query.encode()).hexdigest()
        if cache_key in self.cache:
            return self.cache[cache_key]

        # 2. 混合检索
        semantic_results = await self.semantic_search(query, top_k)
        keyword_results = await self.keyword_search(query, top_k)

        # 3. 结果融合
        merged_results = self.merge_results(
            semantic_results, keyword_results
        )

        # 4. 重排序
        reranked_results = await self.rerank(query, merged_results)

        # 5. 缓存结果
        self.cache[cache_key] = reranked_results

        return reranked_results
```

#### 4.1.2 动态批处理
```python
class DynamicBatchProcessor:
    def __init__(self, max_batch_size=32, timeout_ms=50):
        self.max_batch_size = max_batch_size
        self.timeout_ms = timeout_ms
        self.batch_queue = []
        self.results = {}

    async def process(self, request):
        # 加入批处理队列
        future = asyncio.Future()
        self.batch_queue.append((request, future))

        # 触发批处理
        if len(self.batch_queue) >= self.max_batch_size:
            await self.flush_batch()

        return await future

    async def flush_batch(self):
        if not self.batch_queue:
            return

        # 批量推理
        requests, futures = zip(*self.batch_queue)
        batch_inputs = [req['input'] for req in requests]

        batch_outputs = await self.model.generate_batch(
            batch_inputs
        )

        # 返回结果
        for future, output in zip(futures, batch_outputs):
            future.set_result(output)

        self.batch_queue.clear()
```

### 4.3 异步处理架构

```python
class AsyncThreatAnalyzer:
    def __init__(self):
        self.thread_pool = ThreadPoolExecutor(max_workers=32)
        self.semaphore = asyncio.Semaphore(32)

    async def analyze_async(self, alert_data):
        async with self.semaphore:
            # 异步执行分析
            loop = asyncio.get_event_loop()
            result = await loop.run_in_executor(
                self.thread_pool,
                self._analyze_sync,
                alert_data
            )
            return result

    async def batch_analyze(self, alerts):
        # 创建异步任务
        tasks = [self.analyze_async(alert) for alert in alerts]

        # 并发执行
        results = await asyncio.gather(*tasks)

        return results
```

```python
        # 检测PII（个人身份信息）
        pii_fields = self.pii_detector.detect(data)
```

```python
class AccessController:
    def __init__(self):
        self.rbac = RoleBasedAccessControl()
        self.auth = JWTAuthenticator()

    async def check_permission(self, token, resource, action):
        # 1. 验证JWT Token
        user = await self.auth.verify(token)
        if not user:
            raise UnauthorizedError()

        # 2. 检查角色权限
        if not self.rbac.has_permission(
            user.role, resource, action
        ):
            raise ForbiddenError()

        return True
```

```python
class FailoverManager:
    def __init__(self):
        self.health_checker = HealthChecker()

    async def monitor_and_recover(self):
        while True:
            # 检查主实例健康状态
            is_healthy = await self.health_checker.check_main()

            if not is_healthy:
                # 启动故障恢复
```
