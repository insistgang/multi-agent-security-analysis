### 1.2 各模块功能说明

#### 1.2.1 数据预处理模块
- **功能**: 原始告警日志的标准化处理
- **输入**: 各种格式的安全设备日志
- **输出**: 结构化的告警数据对象
- **关键组件**:
  - 日志格式识别器
  - 字段提取引擎
  - 数据验证器
  - 格式标准化器

#### 1.2.2 路由智能体
- **功能**: 基于告警特征智能选择最适合的专家模型
- **算法**: 规则匹配 + 机器学习分类
- **决策依据**:
  - 攻击类型关键词匹配
  - 网络协议特征
  - 载荷内容分析
  - 历史分类准确率

#### 1.2.3 专家模型群
- **Web攻击专家**: 专注SQL注入、XSS、CSRF等Web层攻击
- **漏洞攻击专家**: 专注CVE利用、0day攻击、权限提升
- **非法外联专家**: 专注C2通信、恶意域名、数据泄露

#### 1.2.4 RAG增强系统
- **向量数据库**: ChromaDB存储威胁情报
- **检索引擎**: 语义相似度匹配
- **知识库**: CVE、MITRE ATT&CK、恶意IP库

#### 1.2.5 结果聚合引擎
- **融合算法**: 加权投票 + 置信度评估
- **冲突解决**: 基于专家权威度和历史准确率
- **输出标准化**: 统一的分析报告格式

### 1.3 数据流向

## 3. 多智能体协同

### 3.1 路由智能体

#### 3.1.1 设计原理
路由智能体是整个系统的核心调度器，负责：
1. **攻击类型识别**: 基于关键词匹配和机器学习
2. **专家选择**: 根据攻击类型选择最适合的专家
3. **负载均衡**: 避免单个专家过载
4. **决策优化**: 基于历史准确率动态调整

#### 3.1.2 路由算法实现

```python
class ExpertRouter:
    def __init__(self):
        self.rules = {
            'web_attack': [
                r'sql|union|select|insert|delete|drop',
                r'xss|script|javascript|onerror|onload',
                r'csrf|token|cross-site|request forgery',
                r'file.upload|\.php|\.asp|\.jsp'
            ],
            'vulnerability': [
                r'cve-\d{4}-\d{4,7}',
                r'exploit|0day|vulnerability',
                r'buffer.overflow|heap.spray',
                r'privilege.escalation|sudo|admin'
            ],
            'illegal_connection': [
                r'c2|command.control|botnet',
                r'malicious.domain|suspicious.domain',
                r'data.exfiltration|data.leak',
                r'tor|proxy|vpn'
            ]
        }
        self.ml_classifier = self._load_classifier()
        self.expert_performance = self._load_performance_metrics()

    def route(self, alert_data):
        # 规则匹配
        rule_scores = self._rule_based_routing(alert_data)

        # 机器学习分类
        ml_prediction = self.ml_classifier.predict(alert_data)

        # 性能权重调整
        weighted_scores = self._apply_performance_weights(rule_scores)

        # 最终决策
        selected_expert = max(weighted_scores, key=weighted_scores.get)
        confidence = weighted_scores[selected_expert]

        return {
            'expert': selected_expert,
            'confidence': confidence,
            'reasoning': self._generate_reasoning(alert_data, selected_expert)
        }
```

#### 3.1.3 路由决策过程

```
输入告警 → 关键词提取 → 规则匹配 → ML分类 → 性能权重 → 最终决策
    ↓         ↓         ↓        ↓        ↓        ↓
  原始日志   特征向量   初步分类  置信度   专家选择  路由结果
```

### 3.3 聚合智能体

#### 3.3.1 融合算法

**加权投票机制**:
```python
class ResultAggregator:
    def __init__(self):
        self.expert_weights = {
            'web_attack': 0.95,
            'vulnerability': 0.93,
            'illegal_connection': 0.94
        }
        self.confidence_threshold = 0.7

    def aggregate(self, expert_results):
        aggregated_analysis = {
            'threat_level': self._calculate_threat_level(expert_results),
            'attack_category': self._determine_attack_category(expert_results),
            'confidence_score': self._calculate_confidence(expert_results),
            'recommended_actions': self._merge_recommendations(expert_results),
            'risk_factors': self._extract_risk_factors(expert_results)
        }

        # 一致性检查
        consistency_score = self._check_consistency(expert_results)
        if consistency_score < self.confidence_threshold:
            aggregated_analysis['disclaimer'] = 'Expert opinions vary, manual review recommended'

        return aggregated_analysis
```

#### 3.3.2 冲突解决策略

1. **权威度权重**: 基于历史准确率的专家权重
2. **置信度考虑**: 优先选择高置信度的分析结果
3. **投票机制**: 多数投票决定最终分类
4. **人工介入**: 自动标记高冲突案例供人工审核

### 3.4 协同机制

#### 3.4.1 消息传递架构

```python
class MultiAgentSystem:
    def __init__(self):
        self.router = ExpertRouter()
        self.experts = {
            'web_attack': WebAttackExpert(),
            'vulnerability': VulnerabilityExpert(),
            'illegal_connection': IllegalConnectionExpert()
        }
        self.aggregator = ResultAggregator()
        self.message_queue = MessageQueue()

    async def analyze_alert(self, alert_data):
        # 路由决策
        routing_decision = await self.router.route(alert_data)

        # 专家分析（并行）
        expert_tasks = []
        for expert_name, confidence in routing_decision['candidates']:
            if confidence > 0.5:
                expert = self.experts[expert_name]
                task = asyncio.create_task(expert.analyze(alert_data))
                expert_tasks.append((expert_name, task))

        # 等待专家结果
        expert_results = []
        for expert_name, task in expert_tasks:
            try:
                result = await asyncio.wait_for(task, timeout=30)
                expert_results.append((expert_name, result))
            except asyncio.TimeoutError:
                logging.warning(f"Expert {expert_name} timed out")

        # 结果聚合
        if expert_results:
            final_result = self.aggregator.aggregate(dict(expert_results))
        else:
            final_result = self._generate_fallback_analysis(alert_data)

class ResourceAllocator:
    def __init__(self):
        self.priority_weights = {
            'threat_severity': 0.4,
            'source_reliability': 0.2,
            'attack_complexity': 0.2,
            'business_criticality': 0.2
        }

        self.resource_tiers = {
            'high': {'model': '7b_expert', 'max_response_time': 2.0},
            'medium': {'model': '4b_distilled', 'max_response_time': 5.0},
            'low': {'model': 'lightweight_classifier', 'max_response_time': 1.0}
        }

    def calculate_priority(self, alert):
        priority_score = 0

        # 威胁严重程度
        severity_map = {'critical': 1.0, 'high': 0.8, 'medium': 0.6, 'low': 0.4}
        priority_score += severity_map.get(alert['threat_level'], 0.5) * self.priority_weights['threat_severity']

        # 源可靠性
        reliability_map = {'siem': 1.0, 'ids': 0.9, 'firewall': 0.8, 'manual': 0.7}
        priority_score += reliability_map.get(alert['source'], 0.6) * self.priority_weights['source_reliability']

        # 攻击复杂度
        complexity_keywords = {
            'apt': 1.0, '0day': 0.95, 'spear_phishing': 0.9,
            'sql_injection': 0.8, 'xss': 0.7, 'brute_force': 0.6
        }
        complexity_score = max([v for k, v in complexity_keywords.items() if k in alert.get('payload', '').lower()], default=0.5)
        priority_score += complexity_score * self.priority_weights['attack_complexity']

        # 业务关键性
        critical_assets = ['database_server', 'web_server', 'domain_controller']
        business_critical = any(asset in alert.get('target', '').lower() for asset in critical_assets)
        priority_score += (1.0 if business_critical else 0.5) * self.priority_weights['business_criticality']

        return min(priority_score, 1.0)

    def allocate_resources(self, alert_batch):
        allocation = {}

        for alert_id, alert in alert_batch.items():
            priority = self.calculate_priority(alert)

            if priority >= 0.8:
                allocation[alert_id] = 'high'
            elif priority >= 0.6:
                allocation[alert_id] = 'medium'
            else:
                allocation[alert_id] = 'low'

        return allocation

class ModelSelector:
    def __init__(self):
        self.model_costs = {
            'qwen2_7b': {'cost_per_request': 1.0, 'accuracy': 0.95, 'response_time': 2.0},
            'distilled_expert': {'cost_per_request': 0.3, 'accuracy': 0.90, 'response_time': 0.8},
            'lightweight_classifier': {'cost_per_request': 0.1, 'accuracy': 0.75, 'response_time': 0.2}
        }

        self.cost_budget = 100  # 每小时最大成本
        self.accuracy_requirement = 0.85

    def select_model(self, alert_priority, current_cost, queue_length):
        affordable_models = [m for m, c in self.model_costs.items()
                           if c['cost_per_request'] <= (self.cost_budget - current_cost) / max(queue_length, 1)]

        if alert_priority >= 0.9:
            # 高优先级使用最佳模型
            return max(affordable_models, key=lambda m: self.model_costs[m]['accuracy'])
        elif alert_priority >= 0.6:
            # 中优先级平衡成本和准确率
            best_model = None
            best_score = 0
            for model in affordable_models:
                score = self.model_costs[model]['accuracy'] / self.model_costs[model]['cost_per_request']
                if score > best_score:
                    best_score = score
                    best_model = model
            return best_model
        else:
            # 低优先级使用最经济的模型
            return min(affordable_models, key=lambda m: self.model_costs[m]['cost_per_request'])
```

class IntelligentCache:
    def __init__(self):
        self.cache = {}
        self.access_patterns = {}
        self.similarity_threshold = 0.8

    def get_cached_result(self, alert):
        # 计算告警特征向量
        alert_features = self._extract_features(alert)

        # 查找相似缓存
        for cached_key, cached_value in self.cache.items():
            similarity = self._calculate_similarity(alert_features, cached_value['features'])
            if similarity > self.similarity_threshold:
                self.access_patterns[cached_key] = self.access_patterns.get(cached_key, 0) + 1
                return cached_value['result']

        return None

    def cache_result(self, alert, result):
        alert_features = self._extract_features(alert)
        cache_key = self._generate_cache_key(alert)

        self.cache[cache_key] = {
            'features': alert_features,
            'result': result,
            'timestamp': time.time()
        }

        # 定期清理低频缓存
        if len(self.cache) > 1000:
            self._cleanup_cache()

    def _cleanup_cache(self):
        # 保留访问频率最高的80%缓存
        sorted_items = sorted(self.access_patterns.items(), key=lambda x: x[1], reverse=True)
        keep_keys = set(key for key, _ in sorted_items[:int(len(sorted_items) * 0.8)])

        self.cache = {k: v for k, v in self.cache.items() if k in keep_keys}
        self.access_patterns = {k: v for k, v in self.access_patterns.items() if k in keep_keys}

class AdaptiveLearning:

                error_patterns = self._analyze_error_patterns(feedback_data)

                patterns['confidence_miscalibration'][feedback['expert']] += 1
