# 网络安全威胁智能分析系统演示

## 演示说明

本演示系统展示了《基于多智能体协同的网络安全威胁智能分析系统》的完整功能和效果。

## 快速开始

### 方式一：HTML静态演示（推荐）

1. 双击运行 `run_demo.py`
2. 选择 "1" 启动HTML演示
3. 浏览器将自动打开演示页面

### 方式二：直接打开HTML文件

1. 进入 `web_demo` 文件夹
2. 双击 `index.html` 文件

### 方式三：Streamlit动态演示

1. 确保安装了streamlit：`pip install streamlit plotly pandas`
2. 运行：`streamlit run demo_app.py`
3. 访问：http://localhost:8888

## 系统要求

- Chrome/Edge/Firefox 等现代浏览器
- 不需要网络连接（本地演示）
- 屏幕分辨率推荐 1920x1080 或更高

## 故障排除

1. **浏览器不自动打开**
   - 手动打开 `web_demo/index.html` 文件

2. **图表不显示**
   - 检查网络连接（需要CDN加载Chart.js）
   - 尝试刷新页面

3. **样式显示异常**
   - 使用Chrome或Edge浏览器
   - 清除浏览器缓存
